# ABMEmpleado — Employee CRUD Management

A full CRUD (Alta, Baja, Modificación) employee management application built with **Angular** and **.NET**.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Backend | C#, ASP.NET Core, Web API |
| Frontend | Angular, TypeScript, Bootstrap |
| Database | SQL Server / MySQL |

## Features

- Create, read, update, and delete employee records
- Form validation
- Data table with search and pagination
- Responsive design
